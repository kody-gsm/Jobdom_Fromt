# 학생 상담 상세 확인·수정 및 신청 폼 제출 필터

## 목표

학생이 대시보드와 마이페이지에서 자신이 신청한 상담의 상세 내용을 다시 확인하고, 선생님이 아직 확정하지 않은 상담은 제목·분야·내용을 수정할 수 있게 한다. 신청 폼 목록에서는 학생이 이미 제출한 폼만 모아 볼 수 있게 한다.

## 범위

### 포함

- 대시보드의 예정 상담 카드 클릭 및 상세 모달
- 마이페이지 상담 카드 클릭 및 동일한 상세 모달
- `WAITING` 상담의 제목·분야·내용 수정 UI
- 수정 성공 후 대시보드·마이페이지 상담 목록 갱신
- 신청 폼 목록의 `내가 제출한 폼` 필터
- 제출 완료 표시와 제출한 폼의 `응답 확인` CTA
- 기존 상담 취소 동작 및 기존 신청 폼 상세의 답변 확인·재응답 동작 유지

### 제외

- 백엔드 코드 변경
- 상담 선생님·상담일·교시 변경 기능
- 신청 폼 일괄 제출 목록 API 추가
- 선생님 페이지 변경

## 사용자 흐름

### 상담 상세

1. 학생이 대시보드 또는 마이페이지에서 예정 상담 카드를 클릭한다.
2. 상담 유형, 선생님, 날짜, 교시, 분야, 제목, 상세 내용을 모달에서 확인한다.
3. 상태가 `WAITING`이면 수정 모드로 전환할 수 있다.
4. 제목·분야·내용을 수정하고 저장한다.
5. 저장 성공 시 모달의 상세 내용과 두 화면의 상담 카드 데이터가 최신 값으로 반영된다.
6. `RESERVED` 또는 `CANCELED` 상태에서는 수정 컨트롤을 표시하지 않는다.

취소 버튼은 상세 클릭과 분리한다. 카드 본문을 클릭하면 상세 모달이 열리고, 카드의 취소 버튼을 클릭하면 기존 취소 확인 흐름만 실행한다.

### 신청 폼 제출 필터

1. 폼 목록의 기본 필터는 기존과 동일하게 `모든 폼`이다.
2. 필터 메뉴에 `내가 제출한 폼`을 추가한다.
3. 제출 여부는 기존 학생 제출 조회 API를 사용해 판단한다.
4. 제출한 카드에는 `제출 완료` 상태를 표시하고, 버튼 문구를 `응답 확인`으로 표시한다.
5. `응답 확인`은 기존 폼 상세 화면으로 이동하며, 기존 답변 확인·재응답 동작을 그대로 사용한다.

## 프론트-백엔드 계약 의존성

최신 백엔드에는 학생 상담 상세 응답과 학생용 수정 API가 이미 반영되어 있다. 프론트 구현은 다음 계약을 사용한다.

- `GET /student/course`, `GET /student/common` 응답에 `teacherId`, `teacherName`, `title`, `content`, `category`, `date`, `period`, `status`가 포함된다.
- `PATCH /student/course/{id}`, `PATCH /student/common/{id}`가 학생 수정 요청을 받는다.
- 수정 API는 본인 예약만 허용하고 `WAITING` 상태에서만 처리한다.
- 수정 요청은 백엔드 `CreateDTO` 계약에 맞춰 `title`, `content`, `category`, `date`, `period`, `teacherId`를 보낸다. 날짜·교시·선생님은 현재 상담 값을 그대로 전달해 수정 대상이 바뀌지 않도록 한다.
- 수정 성공 응답은 최신 상담 객체를 반환하거나, 목록 재조회로 최신 객체를 확인할 수 있어야 한다.

백엔드 저장소는 수정하지 않는다. 최신 백엔드의 수정 API가 배포되지 않은 환경에서는 상담 수정 요청이 실패할 수 있으므로, 프론트 PR 설명에 계약 의존성을 명시한다.

신청 폼 제출 여부는 현재 제공되는 `GET /student/form/{id}/submission`을 폼별로 조회한다. 미제출 404는 정상적인 미제출 상태로 처리하고, 그 외 오류는 제출 여부를 확정하지 못한 상태로 처리한다.

## 상태 및 오류 처리

- 상담 상세 로딩 중에는 로딩 상태를 표시한다.
- 상담 상세 조회 또는 저장 실패 시 모달 안에 사용자에게 이해 가능한 오류를 표시하고 입력값은 보존한다.
- 저장 중에는 저장 버튼을 비활성화해 중복 요청을 막는다.
- 폼 제출 여부 조회 중에는 제출 필터를 사용할 수 있도록 로딩 상태를 표시하거나, 최소한 제출 여부가 확정된 카드만 필터 결과에 포함한다.
- 개별 폼 제출 여부 조회 실패가 전체 폼 목록을 막지 않도록 한다.

## 수용 기준

- 대시보드 예정 상담 카드 본문을 클릭하면 상세가 열린다.
- 마이페이지 상담 카드 본문을 클릭하면 같은 상세가 열린다.
- `WAITING` 상담은 제목·분야·내용을 수정하고 저장할 수 있다.
- `RESERVED`, `CANCELED` 상담은 읽기 전용이다.
- 카드의 취소 버튼은 상세 모달을 열지 않고 기존 취소 흐름을 유지한다.
- 폼 목록의 기본 필터는 `모든 폼`이다.
- `내가 제출한 폼` 필터에서 제출 완료 폼만 표시된다.
- 기존 마감/검색 필터와 제출 여부 필터가 함께 동작한다.
- 기존 폼 상세의 답변 확인·재응답이 깨지지 않는다.
- 단위 테스트와 프로젝트 검증 명령이 통과한다.
